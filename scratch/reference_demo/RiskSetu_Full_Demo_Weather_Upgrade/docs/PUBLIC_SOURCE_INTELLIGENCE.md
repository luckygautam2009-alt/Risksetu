# RiskSetu public-source intelligence
RiskSetu uses zero-cost public RSS/disaster feeds as additional situational-awareness signals. It does not claim unrestricted access to private/social-media firehoses. News/social reports are untrusted leads. The system checks independent-source count and available weather/rainfall context, then exposes confidence and provenance to an authorized officer.

The system must never automatically order evacuation. `PREPARE_EVACUATION_REVIEW` means an officer should inspect evidence, local risk, routes, shelters and official instructions, then decide whether to warn or evacuate.

Current zero-cost sources include GDACS public RSS and Google News RSS search. Existing RiskSetu weather, rainfall, terrain, flood and incident signals remain separate corroborating evidence.
